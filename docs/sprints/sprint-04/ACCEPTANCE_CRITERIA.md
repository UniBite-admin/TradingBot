# Sprint 04 - Acceptance Criteria

Sprint 04 is acceptable only when the data pipeline and evidence posture are honest and reproducible.

## Required completion conditions

1. The sample provenance, file boundaries, and raw-data scope are documented.
2. The local historical archive is reproducible from known source and timestamp semantics.
3. Invalid rows, duplicates, and malformed events are explicitly rejected or quarantined.
4. The design distinguishes bounded exploratory research from statistically representative data coverage.
5. The project preserves the no-backfill and no-lookahead rules.
6. The sprint records explicit blockers for unresolved adequacy and candle semantics.
7. No strategy, paper-trading, or live-trading approval is implied by this sprint.
8. All changes remain in the documentation and data-ingestion planning scope only.

## Required evidence

- file inventory and data-manifest results,
- validation reports for malformed and duplicate events,
- decision log for sample adequacy status,
- stage-gate documentation showing no silent approval.

## Non-criteria

- no positive signal result,
- no strategy profitability claim,
- no implementation approval,
- no paper- or live-trading authorization.
